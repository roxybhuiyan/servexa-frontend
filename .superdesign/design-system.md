# Servexa design system
Primary reference: mosaic-grid-architecture-style. Adapt structural minimalism to a welcoming service marketplace. Paper #F7F7F5, forest #1A3C2B, white surfaces, charcoal #242B27, muted #626A64; mint #9EFFBF accents. High contrast text, 1px #d7ddd6 dividers, no shadows, 2px corners. System sans body and headers, system monospace small labels. Spacing 4/8/12/16/24/32/48/64. Large tight forest headings, restrained uppercase overlines. Responsive 1200px content, grid service cards, useful side navigation on private pages. Mobile single columns and wrapping navigation. 44px controls and visible focus, reduced motion. No fabricated ratings, services, statistics, avatars or testimonials. Empty/loading/error panels must be real. Product: public catalog/detail/provider, customer booking/reviews/payment, provider services/availability/jobs, admin metrics/moderation/audit. Cards show actual API fields only. Hero: 'Good service. Less searching.' Catalog CTA. A geometric green service-path illustration is decorative only. Payment copy never claims success without authoritative paid status. All actual implementation uses React, CSS Modules, typed backend contracts. Use no remote images as fabricated service data.
